# Welcome to Options Supa Site

This site turns off every optional feature of the skin that can be turned off, so its pages show
only the article, the sidebar, and the footer.

## Features

The color-scheme picker, search, the "On this page" sidebar, the breadcrumb trail, the previous
and next page cards, the "Last updated" date, and the "View page source" button are all off.

## Math

`<katexCssCdnUrl>` and `<katexJsCdnUrl>` point KaTeX at self-hosted files, used only on a page
with math. This page has none, so it loads nothing from them.
